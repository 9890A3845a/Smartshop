# SmartShop V1.1 — simple comparison prototype

A mobile-friendly, static South African shopping comparison prototype.

## What's improved in V1.1
- Products are shown in a straightforward list rather than a multi-column card grid.
- Each product has a clear **Add to compare** button.
- A comparison bar appears at the bottom of the screen after the first product is selected. It shows how many products are selected and provides a direct **Compare selected products** action.
- Users can select up to three products, remove individual products, or clear the selection.
- The comparison table remains below the product list.

## Open on Android
1. Open the published SmartShop website in Chrome.
2. Use the browser menu to add it to your home screen if you want an app-like shortcut.

## Important limitations
- The example catalogue is demonstration data, not current retailer pricing.
- Products entered by the user are saved in that browser's local storage only. They are not shared between devices and may be lost if browser data is cleared.
- There are no live retailer feeds, user accounts, cloud database, price alerts or affiliate links yet.
- The value score is an experimental guide, not an independently verified product rating. Verify product details and prices with the retailer before buying.

## Files
- `index.html` — page structure
- `styles.css` — visual design and responsive layout
- `app.js` — product list, selection, comparison and local saving

This is an early prototype for usability testing, not yet a production shopping platform.
